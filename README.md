# Python Data & Text Analyzer Utility

### Project Description
This is a lightweight Python utility script developed to demonstrate foundational logical reasoning and data structure manipulation capabilities. It focuses on parsing input text strings, extracting metadata, and performing basic data analysis.

### Features
1. *Core Data Structure Handling:* Demonstrates the use of Python Dictionaries (Hash Maps) for frequency calculation, Lists (Arrays) for storage, and String manipulation.
2. *Logical Reasoning:* Implements conditional logic to filter and categorize data based on specific constraints (e.g., filtering words by length).
3. *Basic Data Preprocessing:* Preforms elementary cleaning operations (e.g., removing basic punctuation and standardizing casing) useful for preparation in NLP or logical analysis tasks.
